# NEP Korea v65 운영판

넵코리아 음식물류 폐기물 수거관리 시스템.

## 운영 앱
https://nepkoreateam.github.io/nep-korea-system/?v=65

## 이번 릴리스
- 운영 Supabase Auth 로그인, 실제 계정 권한 검증, 세션 복구
- 시연 데이터와 실제 경영현황 분리, 업체 CRM/민원 히스토리 및 직책별 경영회의 유지
- 관리자 전용 전체 장부·문자 대기열, 기사별 배정·수거·주유·공장중량 접근 분리
- 수거기록 및 코스 순서를 PostgreSQL 트랜잭션으로 저장
- 월 수거기록 페이지 단위 전체 조회, 최신 조회 실패 시 관리대장 발송대기 중단
- 관리자 장부 동시 수정 감지, 샘플 초기화·가짜 로그인 계정 저장 차단
- GitHub Pages의 기존 URL 유지, 서비스워커가 외부 인증·DB 요청에 개입하지 않도록 수정

## 데이터베이스
`10_nep_v65_production.sql`은 기존 운영 데이터 보존, 제한된 백업, CRM 테이블, 역할별 권한 및 RPC를 포함한다. 기존 프로젝트에 적용 완료. 재실행하지 말고 향후 DB 변경은 별도 검증된 마이그레이션으로 적용한다.

## 운영 주의
- Auth 계정 등록·비밀번호 변경은 Supabase Authentication에서 수행하며 앱에 평문 비밀번호를 저장하지 않는다.
- 경영현황 시연 수치는 실제 고객 데이터에 저장하지 않는다.
- KT Relay는 기존 Windows PC 프로그램으로 발송하며, 실제 고객 발송 전에 테스트 번호로 검증한다.
- 무료 프로젝트의 비활성 일시정지는 요금제 정책에 따른다. 운영 서버의 상태와 백업을 주기적으로 점검한다.
