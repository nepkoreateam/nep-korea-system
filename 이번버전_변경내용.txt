NEP Korea v45 Supabase 로그인 + AppState 저장 연결

변경 내용
1. GitHub Pages에서도 Supabase Auth로 로그인합니다.
2. 로그인 아이디 칸에 admin 또는 nepkoreateam@gmail.com을 입력할 수 있습니다.
3. 전체 앱 상태를 Supabase app_states 테이블에 JSON으로 저장합니다.
4. 기존 v44 화면과 기능은 유지했습니다.
5. 다음 단계에서 업체관리/오늘배정/기사앱을 정규 테이블(customers, routes, pickup_records 등)로 하나씩 연결합니다.

주의
- 이 버전은 실제 DB 연결 1단계입니다.
- 먼저 02_NEP_Supabase_AppState_v45.sql을 SQL Editor에서 실행해야 합니다.
- Secret key 또는 service_role key는 절대 GitHub에 올리지 마세요.
