NEP Korea v45 GitHub 업로드 방법

1. Supabase SQL Editor에서 02_NEP_Supabase_AppState_v45.sql 먼저 실행
2. 이 폴더 안의 파일 전체를 GitHub nep-korea-system 저장소에 업로드

4. 업로드 후 GitHub Pages 주소 뒤에 ?v=45&fresh=1 붙여서 접속
