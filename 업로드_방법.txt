GitHub 업로드 방법

1. ZIP 압축 풀기
2. 'NEP_Korea_v44_GitHubPages_최종깔끔업로드용' 폴더 열기
3. 폴더 안의 파일과 폴더를 전체 선택
4. GitHub 저장소 nepkoreateam/nep-korea-system 접속
5. Add file > Upload files
6. 전체 파일을 끌어다 놓기
7. Commit changes 클릭

중요:
- 폴더 자체를 올리지 말고 폴더 안의 내용물을 올리세요.
- 기존 저장소에 예전 server.js, package.json, data, public, .bat 파일이 남아 있으면 GitHub Pages 작동에는 필요 없습니다.
- 깔끔하게 하려면 기존 불필요 파일을 삭제하고 이 ZIP 안의 파일만 남기세요.
